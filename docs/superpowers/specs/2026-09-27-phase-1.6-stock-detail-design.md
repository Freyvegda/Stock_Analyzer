# Phase 1.6 — Stock Detail Page (design)

**Date:** 2026-09-27
**Status:** Approved design, pending implementation
**Branch:** `phase-1.6`
**Phase plan:** `plan/phase-1.6-stock-detail/{backend,frontend,database}.md`

## 1. Goal

From the screen shortlist, a user clicks a company and lands on its own page
(`/stock/:symbol`) showing:

1. a **computed stock report** — verdict against *that user's* selected criteria,
   score, per-criterion pass/fail, notes;
2. the **fundamentals** of the stock (catalog metric groups from the stored
   snapshot);
3. a **daily chart** (candles) with 15-day and monthly aggregation options.

Stock data is shared by all users; the verdict is per user. Fundamentals are
stored in the database on first view / manual refresh so later visitors read the
DB directly. Daily price data is **never stored** in the database.

## 2. Locked decisions

| Decision | Choice |
|---|---|
| Storage | No new tables. `stocks` + `fundamentals` stay global/shared; first view lazy-fetches and upserts a dated snapshot; manual Refresh button forces a re-fetch |
| Verdict | Computed per request against the caller's **current saved criteria**; never persisted (two users see identical fundamentals and different verdicts) |
| Prices | Never written to the DB. Backend keeps an in-process TTL cache (900 s, per symbol, 5y daily rows) and slices/aggregates from it |
| Chart ranges | `6m` / `1y` (default) / `2y` / `5y` |
| Chart intervals | `1d` (default) / `15d` (fixed 15-calendar-day buckets) / `1mo` (calendar-month buckets) |
| 3D | New **Candle Ridge** hero scene on the stock page: lazy WebGL chunk, data-driven (stock's own closes), brand palette only, gated like the 3D kit, one loop — added to DESIGN.md's whitelist |
| Route | `/stock/:symbol` inside the auth shell; shortlist symbol cell becomes a link |
| Reports | Deterministic and computed from stored data + catalog. No AI (Phase 2 owns AI doc analysis) |

## 3. Backend

### 3.1 New package `app/stock/`

- `candles.py` — pure range slicing + interval aggregation + TTL cache.
  - `RANGES = {"6m": 182, "1y": 365, "2y": 730, "5y": 1825}` (calendar days before the last bar).
  - `slice_range(rows, range_key)` — keeps rows with `date >= last_date - days`.
  - `aggregate_candles(rows, interval)` — `1d` passthrough; `15d` buckets by
    `ordinal // 15`; `1mo` buckets by `YYYY-MM`; per bucket: `time` = first date,
    `open` = first open, `close` = last close, `high` = max, `low` = min,
    `volume` = sum. Rows are ascending by date.
  - `CandleCache(ttl_seconds=900.0, clock=time.monotonic)` with
    `get_or_fetch(symbol, loader)`, `invalidate(symbol)`; module-level
    `default_cache`. Failures are never cached.
- `report.py` — pure `build_report(snapshot, criteria) -> dict`:
  - `verdict`: `"pass"` when every enabled criterion passes, else `"fail"`.
  - `score`: engine formula `roe + roce − 20 × debt_to_equity` (missing → 0), rounded 2.
  - `criteria`: enabled criteria in order —
    `{key, label, unit, direction, threshold, value, passed, delta}`.
    `value` is the catalog-resolved value (`None` fails, as in the engine).
  - `notes`: deterministic strings for failed criteria only
    (above your limit / below your minimum / no stored data).
  - `groups`: catalog metrics grouped by `RatioSpec.category`, in catalog order,
    `{category, metrics: [{key, label, unit, value}]}`, `None` values skipped.
- `service.py` — orchestration (thin API layer rule):
  - `get_stock_detail(session_factory, provider, user_id, symbol) -> dict`
    - unknown symbol (not in `stocks`) → `StockNotFound`
    - newest `ok` row exists → serve it, **zero network**
    - no row → fetch, store (`merge` symbol+today), update `stocks.market_cap`
      when present; fetch failure → write a `failed` row (only when today has no
      `ok` row) then `StockDataUnavailable`
  - `refresh_stock(...)` — force fetch; success → stored, `refreshed=True`;
    failure with a stored `ok` row → serve stored, `refreshed=False`,
    `warning=<reason>`; failure with nothing stored → `StockDataUnavailable`
  - `get_ohlc(session_factory, provider, symbol, range_key, interval, cache)` —
    unknown symbol → `StockNotFound`; fetch via cache (`provider.ohlc(symbol, years=5)`);
    empty → `PriceDataUnavailable`; slice + aggregate.
  - `stale` = snapshot date != today. `run` = symbol's entry (rank/score) in the
    caller's latest `ScreenRun`, or `None`.
- `app/api/stock.py` — thin router, `get_provider()` + `default_cache` at module
  level (monkeypatched in tests), mounted at `/stock` behind `current_user`.

### 3.2 API contract

`GET /stock/{symbol}` and `POST /stock/{symbol}/refresh` (symbol trimmed, uppercased):

```json
{
  "symbol": "RELIANCE",
  "name": "Reliance Industries Ltd",
  "sector": "Oil & Gas",
  "market_cap": 1900000.0,
  "snapshot": {
    "date": "2026-09-27",
    "pe": 24.1, "pb": 2.1, "roe": 8.9, "roce": 9.4,
    "debt_to_equity": 0.42, "data_status": "ok"
  },
  "report": {
    "verdict": "pass",
    "score": 10.3,
    "passed": 5,
    "enabled": 5,
    "criteria": [
      {"key": "pe", "label": "P/E", "unit": "×", "direction": "max",
       "threshold": 25.0, "value": 24.1, "passed": true, "delta": -0.9}
    ],
    "notes": [],
    "groups": [
      {"category": "Valuation",
       "metrics": [{"key": "pe", "label": "P/E", "unit": "×", "value": 24.1}]}
    ]
  },
  "data_date": "2026-09-27",
  "stale": false,
  "run": {"run_id": 3, "run_date": "2026-09-27", "rank": 2, "score": 10.3},
  "refreshed": null,
  "warning": null
}
```

`GET /stock/{symbol}/ohlc?range=6m|1y|2y|5y&interval=1d|15d|1mo`
(defaults `1y`, `1d`; invalid values → 422):

```json
{"symbol": "RELIANCE", "range": "1y", "interval": "1d", "as_of": "2026-09-26",
 "candles": [{"time": "2025-09-26", "open": 1.0, "high": 1.1, "low": 0.9, "close": 1.05, "volume": 123}]}
```

Errors: 404 unknown symbol; 502 `Stock data unavailable: …` /
`Price data unavailable: …`; 401 unauthenticated (global).

### 3.3 Provider

`YFinanceProvider.ohlc(symbol, years=5)` finally implemented (Phase 3 reuses it):
`yf.Ticker(f"{symbol}.NS").history(period=f"{years}y", interval="1d")` →
ascending rows `{time: "YYYY-MM-DD", open, high, low, close, volume}`;
NaN-close rows dropped; empty frame → `[]`. Network errors propagate (API maps
them to 502).

### 3.4 Shared helpers touched

- `engine._resolve` → public `engine.resolve_value`; `engine._enabled_criteria`
  → public `engine.enabled_criteria`; scoring extracted to `engine.score_row`
  (used by `rank_shortlist` and `report.build_report`). Behavior unchanged;
  existing engine tests are the regression gate.

## 4. Database (no schema change)

- `fundamentals(symbol, date PK)` remains the shared snapshot store; composite-PK
  `merge` keeps re-fetches idempotent per day.
- New write rule: a failed fetch writes a `failed` row **only when no `ok` row
  exists for that symbol+day** (never clobbers a good same-day snapshot).
- `prices` stays untouched until Phase 3. The candle path performs no writes —
  a test asserts row counts are unchanged after `/stock/{symbol}/ohlc`.
- `DATABASE.md` records the policy: shared stock data, per-user verdict computed
  on read, daily bars memory-cached only.

## 5. Frontend

### 5.1 Page — `pages/StockDetail.tsx` (`/stock/:symbol`)

- Fetch `GET /stock/{symbol}` and `GET /stock/{symbol}/ohlc?range=…&interval=…`
  in parallel on mount; range/interval changes refetch the chart only.
- Section order:
  1. header: back link to `/`, symbol + name, sector badge, market cap `Num`,
     data-as-of, Refresh button (pending state), run chips (rank/score);
  2. hero strip (~140px, `hidden md:block`, no text over the canvas) with lazy
     `CandleRidge` fed by the loaded candles;
  3. `StockReportCard` — verdict badge, score, per-criterion rows with pass/fail
     glyph + sr text, notes;
  4. fundamentals grid — `report.groups` tiles (`Num` + unit, catalog labels);
  5. chart card — range switcher (6M/1Y/2Y/5Y) + interval switcher
     (Daily/15D/Monthly, `aria-pressed`), `StockChart`, skeleton, error + retry.
- 404 → "Unknown symbol" + back link; 401 rides the global `auth:unauthorized`.
- Refresh warning (stored data served after a failed fetch) → toast + inline note.

### 5.2 `components/StockChart.tsx`

Implements the existing FRONTEND.md contract `{candles, markers?}` so Phase 3
only passes markers. lightweight-charts v5: `createChart` +
`chart.addSeries(CandlestickSeries, …)` + `createSeriesMarkers`; colors from
`chartPalette` (no hex literals in chart code); color-mode switch re-applies
options; `ResizeObserver` guarded for jsdom; `chart.remove()` on unmount.

### 5.3 `components/three/CandleRidge.tsx` + `candleRidge.ts`

- Pure helpers (three-free, unit-tested): `ridgeValues` (last ≤96 closes),
  `normalizeRidge` (0..1, flat → 0.5), `ridgeTones` (delta-based brand ladder),
  `barLayout` (centered widths), `easeOutCubic`, `barProgress` (staggered).
- Scene: instanced low-poly bars rise in a staggered entrance (320 ms + 6 ms/bar),
  then a slow yaw sway loop; brightness on the brand ladder only (never
  gain/loss polarity). Renders `null` without WebGL or below `md`; frozen
  assembled pose / no loop under reduced motion; paused while the tab is hidden;
  `aria-hidden`, `pointer-events-none`. Lazy chunk — three.js must not enter the
  initial bundle.
- DESIGN.md gains a "Stock hero — Candle Ridge" section and one loop-whitelist
  entry (stock detail only).

### 5.4 Navigation

`ShortlistTable` symbol cell becomes a `<Link to={/stock/${symbol}}>`; existing
table tests get a `MemoryRouter` wrapper.

## 6. Error handling

- Per-stock isolation everywhere: a failed fundamentals/ohlc fetch affects only
  that stock's page; stored snapshots keep the page alive with `warning`/`stale`.
- `stale` badge when `data_date != today` (matches the Fundamentals page).
- Chart errors show inline error + Retry; never a blank card.
- 401 on any call → existing global redirect to `/login`.

## 8. Acceptance

- Clicking a shortlisted symbol opens `/stock/{symbol}`; page shows report,
  fundamentals and the daily chart.
- First view fetches and stores the snapshot; a second user's view makes no
  fundamental network call and sees the same stock data; verdicts differ per
  user criteria.
- Refresh forces a new snapshot; on upstream failure the page still shows the
  stored data with a warning.
- Chart supports 6M/1Y/2Y/5Y × Daily/15D/Monthly; no price row is ever written.
- Backend suite, frontend suite and build green; docs updated; `graphify update .` run.
