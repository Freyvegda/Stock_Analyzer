# Phase 1.5 Backend — Auth, Per-User DB Screener, Ratio Catalog (Backend + Database) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend half of Phase 1.5: cookie-session auth, per-user criteria stored in the DB (YAML retired), a code-owned dynamic ratio catalog, and a user-scoped screen run/history.

**Architecture:** New `app/auth/` package (scrypt hashing, user service, `current_user` dependency) + Starlette `SessionMiddleware` (`sa_session` cookie, no sessions table); `app/screener/catalog.py` owns valid ratio keys; `app/screener/criteria.py` owns pydantic validation + defaults; `engine.py` switches from a static YAML dict to a per-user criteria list resolving `derived` columns or `raw` `.info` fields; `screen_runs` gains `user_id` + `criteria_json` and loses `config_yaml`. Router gating: `/docs`, `/model`, `/backtest` at include level; `/screen/*` per-route.

**Tech Stack:** Python 3.10, FastAPI, Starlette `SessionMiddleware` + `itsdangerous` (new dependency), SQLAlchemy 2.x / SQLite, pydantic v2, stdlib `hashlib.scrypt`, pytest (offline; sessions signed directly in test helpers).

**Spec:** `docs/superpowers/specs/2026-09-26-phase-1.5-authorization-db-screener-design.md` (the plan argues from it; executors read both).

## Global Constraints

- Binding context docs updated in the same change: `backend/BACKEND.md`, `backend/app/db/DATABASE.md`, `PLAN.md`, plus new `plan/phase-1.5/backend.md` + `plan/phase-1.5/database.md`.
- Budget ₹0: no external auth provider; stdlib scrypt only (no passlib/bcrypt/authlib).
- Session cookie: name `sa_session`, HttpOnly (Starlette default), SameSite=lax, `Secure=False`, `max_age = 30 * 24 * 60 * 60`; secret `secrets.token_urlsafe(32)` persisted at `data/.session_secret` (gitignored by `/data/`).
- Password format `scrypt$n$r$p$<salt_b64>$<hash_b64>` with n=2^14, r=8, p=1, 16-byte salt; verify with `secrets.compare_digest`. Password min length 8; username trimmed + lowercased, 3–32 chars.
- `shortlist_size` is server-owned: never accepted from the client (presence in a `PUT /screen/criteria` payload → 422); engine clamps to `min(value, 10)`.
- Tests run offline — mock all network; sign session cookies directly (`tests/conftest.py` helper), no HTTP login dance in fixtures.
- Schema stays Postgres-compatible; dev DB is disposable (delete file → `init_db()` rebuilds).
- `pip install` on this machine always uses `--isolated`.
- Every `/screen/*` route requires a session; `/health` and the public `/auth` routes are exempt. All 401 bodies: `{"detail": "Not authenticated"}`.

## Review Focus

Input classes/failure modes the spec implies but individual tasks might not pin; each has a test in the owning task:

1. Two-tab setup race → second `POST /auth/setup` returns 409 and login page can recover (test in Task 6).
2. Raw catalog field missing/NaN for some stocks → only those stocks fail that criterion; run continues (test in Task 8).
3. Tampered DB `shortlist_size = 50` → run still returns ≤ 10 rows (test in Task 9).
4. `PUT /screen/criteria` payload carrying `shortlist_size` → 422, value never stored (tests in Tasks 3 + 7).
5. Tampered/expired session cookie → 401 clean, no crash, no loop (test in Task 6).
6. Corrupt `criteria_json` in the DB → `GET /screen/criteria` falls back to Phase-1 defaults instead of 500 (test in Task 7).
7. Username casing/whitespace (`"  Alice  "` → `alice`) authenticates case-insensitively; duplicate create conflicts (tests in Task 5).
8. Pipeline routers other than `/screen` (`/docs`, `/model`, `/backtest`) require a session too (test in Task 6).

```python
    if spec.source == "derived":

        if value is None:

    if math.isnan(value) or math.isinf(value):
```

```python
"""Manual, online-only check: raw catalog scales vs live yfinance .info.

Run from backend/:  python -m scripts.verify_catalog
Never part of the offline test suite.
"""
from app.screener.catalog import RATIO_CATALOG

TICKERS = ("RELIANCE", "TCS", "HDFCBANK")


def main() -> None:
    import yfinance as yf

    infos = {s: (yf.Ticker(f"{s}.NS").info or {}) for s in TICKERS}
    for spec in RATIO_CATALOG:
        if spec.source != "raw":
            continue
        parts = []
        for symbol in TICKERS:
            value = infos[symbol].get(spec.yf_field)
            scaled = round(float(value) * spec.scale, 4) if isinstance(value, (int, float)) else None
            parts.append(f"{symbol}={value!r}->{scaled}{spec.unit}")
        print(f"{spec.key:28} {spec.yf_field:32} scale={spec.scale:<5} " + "  ".join(parts))


if __name__ == "__main__":
    main()
```
